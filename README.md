# Lógica Computacional

Repositorio académico para organizar y documentar ejercicios de la asignatura Lógica Computacional. El proyecto reúne actividades prácticas orientadas al diseño de algoritmos y a la solución de problemas mediante pseudocódigo, diagramas y programación en C++.

## Objetivo

Practicar los fundamentos de la lógica computacional mediante el análisis de problemas, la identificación de entradas y salidas, el diseño de algoritmos y su implementación en C++.

## Contenido del repositorio

Según las carpetas visibles en el repositorio, las actividades están organizadas por módulo:

| Carpeta | Descripción |
| --- | --- |
| `Actividad 1 Modulo 3/` | Material y soluciones correspondientes a la primera actividad del módulo 3. |
| `Actividad 2 Modulo 3/` | Material y soluciones correspondientes a la segunda actividad del módulo 3. |

Consulta cada carpeta para conocer los enunciados, documentos y archivos incluidos en la actividad correspondiente.

## Temas de práctica

Las actividades del módulo pueden incluir los siguientes contenidos, según el ejercicio desarrollado:

- Análisis de problemas y definición de entradas, procesos y salidas.
- Diseño de algoritmos mediante pseudocódigo.
- Representación de procesos con diagramas de flujo o DFD, cuando corresponda.
- Estructuras selectivas.
- Estructuras repetitivas, como `Mientras`.
- Uso de contadores y acumuladores.
- Codificación y ejecución de soluciones en C++.
- Pruebas de escritorio para comprobar los resultados.

## Herramientas

- Lenguaje de programación: C++.
- Entorno de desarrollo utilizado: CLion.
- Control de versiones y publicación del material: Git y GitHub.

## Cómo consultar el proyecto

1. Abre la carpeta de la actividad que necesitas revisar.
2. Lee el enunciado del ejercicio.
3. Identifica el análisis, el algoritmo y la solución programada que se incluyan.
4. Si hay código C++, ábrelo en un entorno compatible y compílalo antes de ejecutarlo.
5. Compara la salida del programa con los resultados esperados del ejercicio.

## Propósito académico

Este repositorio sirve como registro de práctica y seguimiento del aprendizaje de lógica computacional y programación. Las soluciones se pueden utilizar para estudiar el razonamiento algorítmico, comparar métodos y mejorar la documentación del código.
